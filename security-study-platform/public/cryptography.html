학습 플랫폼으로 돌아가기

1. 암호학의 4대 보안 목표

기밀성

허가받지 않은 사람이 내용을 읽지 못하도록 암호화합니다.

무결성

데이터 변경·변조 여부를 Hash, MAC 등으로 확인합니다.

인증

사용자·시스템·메시지의 진위를 MAC, 전자서명, 인증서로 확인합니다.

부인방지

송신자가 자신의 행위를 부인하지 못하도록 전자서명을 사용합니다.

2. 대칭키 암호와 AES

대칭키 암호는 암호화와 복호화에 동일한 공유 비밀키를 사용합니다. 대표 알고리즘은 AES, DES/3DES, SEED, ARIA이며 RC4는 대표적인 스트림 암호입니다.

AES-128

128bit 블록 · 128bit 키 · 10 Round

AES-192

128bit 블록 · 192bit 키 · 12 Round

AES-256

128bit 블록 · 256bit 키 · 14 Round

AES Round: SubBytes → ShiftRows → MixColumns → AddRoundKey. 마지막 Round에서는 MixColumns를 수행하지 않습니다.

3. 블록 암호 운영 모드

ECB

각 블록을 독립적으로 암호화합니다. 동일한 평문 블록이 동일한 암호문 블록이 되어 패턴이 노출될 수 있습니다.

CBC

현재 평문과 이전 암호문을 XOR 후 암호화합니다. 첫 블록에는 IV가 필요합니다.

CFB / OFB

블록 암호를 스트림 형태로 활용합니다. Feedback과 오류 전파 특성을 구분합니다.

CTR

Counter 값을 암호화하여 Key Stream을 만들며 병렬 처리가 가능합니다.

4. 공개키 암호

RSA

암호화와 전자서명에 활용하며 큰 정수 소인수분해의 어려움에 기반합니다.

Diffie-Hellman

공유 비밀값을 합의하는 방식입니다. 기본형은 상대방 인증을 제공하지 않아 MITM 방어를 위해 인증이 필요합니다.

ECC

타원곡선 이산로그 문제에 기반하며 키 합의와 전자서명 계열에 활용됩니다.

DSA / ElGamal

DSA는 전자서명, ElGamal은 공개키 암호 계열로 분류합니다.

5. RSA 계산 순서

  1. 서로 다른 소수 p, q 선택
  2. n = p × q
  3. φ(n) = (p-1)(q-1)
  4. gcd(e, φ(n)) = 1인 e 선택
  5. e × d ≡ 1 (mod φ(n))을 만족하는 d 계산

공개키: (e, n) · 개인키: (d, n)

암호화: C = Me mod n · 복호화: M = Cd mod n

6. Hash · MAC · HMAC

Hash

임의 길이 입력을 일정 길이 Digest로 변환합니다. MD5와 SHA-1은 충돌 취약성 때문에 현대 보안 용도로 사용하면 안 됩니다.

Birthday Attack

이상적인 n비트 해시의 충돌 공격 복잡도는 대략 2^(n/2)입니다.

MAC / HMAC

비밀키를 사용해 메시지의 무결성과 인증을 제공합니다. 공유키 방식이므로 전자서명과 같은 부인방지는 제공하지 않습니다.

7. 전자서명 키 사용 방향

기밀성 암호화

수신자의 공개키로 암호화 → 수신자의 개인키로 복호화

전자서명

송신자의 개인키로 서명 → 송신자의 공개키로 검증

전자서명은 주로 인증 + 무결성 + 부인방지를 제공합니다.

8. PKI · X.509 · 인증서 상태

CA

인증서를 발급하고 서명합니다.

RA

인증서 신청자의 신원을 확인하고 등록을 지원합니다.

X.509

주체의 신원 정보와 공개키를 연결하는 대표적인 인증서 표준입니다.

CRL / OCSP

CRL은 폐기 인증서 목록, OCSP는 인증서 상태를 온라인으로 확인하는 방식입니다.

9. Salt와 비밀번호 저장

사용자마다 고유한 Salt를 적용하면 동일 비밀번호의 저장값이 같아지는 것을 막고 Rainbow Table 같은 사전 계산 공격을 어렵게 합니다. 비밀번호 저장에는 일반 SHA-256 단독 사용보다 PBKDF2, bcrypt, scrypt, Argon2 같은 비밀번호 해싱/KDF를 사용합니다.

10. 암호 공격 모델

COA

암호문만 알고 있는 공격

KPA

일부 평문과 대응 암호문을 알고 있는 공격

CPA

원하는 평문을 선택해 암호문을 얻을 수 있는 공격

CCA

원하는 암호문을 선택해 복호화 결과를 얻을 수 있는 공격

11. 정보보안기사 핵심 암기

  • AES → 대칭키 · 128bit 블록
  • RSA → 공개키 · 소인수분해
  • Diffie-Hellman → 키 합의
  • ECC → 타원곡선 이산로그 문제
  • HMAC → 무결성 + 메시지 인증
  • 전자서명 → 인증 + 무결성 + 부인방지
  • CBC → 첫 블록에 IV 필요
  • ECB → 동일 평문 블록 패턴 노출 위험
  • CRL → 인증서 폐기 목록 · OCSP → 인증서 상태 확인
